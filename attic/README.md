# attic — написано, но не подключено к сборке

Ничто здесь не входит в x86-64/ARM64 образ и не покрыто сценариями QEMU. Состояние каждого модуля:

| Каталог | Что | Почему здесь | Что нужно для возврата |
|---|---|---|---|
| `acpi-prt/` | три независимых разборщика ACPI AML `_PRT` | в ядре нет маршрутизации по `_PRT`; три реализации одной задачи, ни одна не используется | выбрать одну, подключить к `pci.c`/`ioapic`, тест на таблицах QEMU q35 |
| `iommu/` | AMD-Vi, домены ARM SMMU, discovery, `iommu_vtd_hw` | не линкуются; рабочий путь — `iommu.c`/`iommu_vtd.c` | подключить, сценарий DMA-изоляции в QEMU (`-device intel-iommu`) |
| `boot/` | `kdrv_manager`, `boot_handoff`, `fdt_boot` | нет вызывающих | решение по BootInfo RFC |

Историю веток с лабораторными материалами см. в git (удалён каталог `research/`).
