# Требования и ограничения владельца (извлечено из журнала и диалога)
Источники: CG-20261109-013 §2, диалог владельца (Claude Code сессия), docs/UNIFIED_RELEASE_PLAN.md, docs/BUILDER_PLAN.md.

| № | Требование | Откуда |
|---|---|---|
| R1 | Целевые CPU: x86-64 и ARM64 на обычном массовом железе, без особых ускорителей | CG-013 |
| R2 | ОС не зависит от драйверов производителя «под KIRA»; нужен конвейер: легальный поиск открытых драйверов → анализ → адаптация → пересборка → проверка; успешная компиляция ≠ поддержка | CG-013 |
| R3 | Собственный ИИ «Разум» (диагностика, оптимизация, помощь в разработке, ресурсы) БЕЗ безусловных привилегий: посредник политик, подпись, подтверждение человеком | CG-013, диалог |
| R4 | Максимальная эффективность и качество; допускаются свои форматы/ABI, если выигрыш доказан и стоимость посчитана | CG-013 |
| R5 | Никаких заглушек, фиктивных тестов, PASS без запуска; честная маркировка PREVIEW, пока гейты открыты | CG-013, диалог |
| R6 | Свой компилятор KCC внутри ОС: быстрый, корректный, итоговый код сверхоптимизированный и «мега-корректный», не хуже clang по скорости и качеству; цель: среднее ≤+10%, худший ≤+25% | диалог, BUILDER_PLAN |
| R7 | Своя цепочка: ассемблер KAS, компоновщик KLINK, загрузчики BIOS и UEFI; автономность от clang/nasm/ld.lld | диалог |
| R8 | Защита памяти: W^X, IOMMU/DMA-изоляция, анти-откат, подпись; DMA Ring3 только при реальной изоляции | диалог, RELEASE_GAPS |
| R9 | «Цех с боксами»: параллельная сборка, ИИ и пользователь пишут программы простыми инструкциями (будущий язык/приложение) | диалог |
| R10 | Графический интерфейс — потом, по образцам владельца; в исследование не входит | диалог |
| R11 | Ответы по-русски, экономия токенов, помощники только при выгоде, проверка их результата | предпочтения |
| R12 | Не сливать PR #44/#46 и не менять main без разрешения | CG-013 §9 |
| R13 | Не путать Linux/PRoot-результаты с результатами KIRA на железе | CG-013 §3F |
