# KIRA v44 — домашняя карточка рабочего стола

На экранах не меньше 900×620 справа внизу рабочего стола отображается компактный обзор системы:

- средняя загрузка доступных ядер CPU;
- занятость памяти;
- здоровье Mind;
- часы из системного источника времени.

Карточка строится из значений, переданных оконному менеджеру через wm_set_clock и wm_set_meters. Она не читает внутренние структуры ядра и не выполняет системных действий. Если значение отсутствует (отрицательный sentinel), интерфейс показывает «нет данных», а не нулевой процент. При изменении часов или телеметрии перерисовывается только область карточки и верхняя панель.

Боковой Dock остаётся быстрым запуском программ; карточка — пассивным обзором, а не набором фиктивных кнопок.

Проверка: tests/wm_test.c проверяет отрисовку карточки после сворачивания окон и передачи реальных тестовых значений. GUI-регрессии проверяют сборку и геометрию оболочки.
