# Архитектурный syscall ABI KIRA

## Общий контракт

Ядро принимает один и тот же логический вызов на обеих архитектурах: номер + три 64-битных аргумента; возвращает 64-битный результат.

| Поле | x86-64 | ARM64 |
|---|---|---|
| Номер | RAX | X8 |
| Аргумент 1 | RDI | X0 |
| Аргумент 2 | RSI | X1 |
| Аргумент 3 | RDX | X2 |
| Результат | RAX | X0 |
| Вход | SYSCALL | SVC #0 |

Архитектурные entry-коды только раскладывают регистры в общий обработчик syscall. Проверка указателей, полномочий и семантика вызовов остаются в общем ядре.

## Единый источник номеров

Файл kcc/include/syscall_abi.h задаёт номера один раз и предоставляет имена SYS_* для ядра и K_* для обеих userland-библиотек. Этот заголовок автоматически попадает в /etc/kcc/include при сборке x86-64 и ARM64.

## Проверка

tests/syscall_abi_test.c компилируется дважды: с API-заголовком из userland/ и с заголовком из kcc/include/. Статические проверки фиксируют совпадение номеров ядра и userland и не допускают незаметного изменения ABI-номеров.

Это проверяет согласованность таблицы вызовов, но само по себе не доказывает полный функциональный паритет архитектур. Для него отдельно нужны одинаковые сценарии запуска, потоков, IPC, памяти, файловой системы, сети и драйверов на x86-64 и ARM64.
