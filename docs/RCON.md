# Удалённая консоль по TCP (rcon)

Те же команды, что в терминале, и тот же вывод (журнал ядра) - по сети. Для тестов в VirtualBox и на железе,
когда рядом нет серийного кабеля, и чтобы Claude мог работать с ОС через связанный компьютер.

Включение (в терминале Киры):
- `rcon passwd ПАРОЛЬ` - пароль от 8 знаков (хранится хешем с солью в /var/rcon.key);
- `rcon on [порт]` - включить, порт по умолчанию 7077; включение сохраняется в /var/rcon.conf и переживает перезагрузку;
- `rcon off`, `rcon status`.

Клиент: `nc АДРЕС 7077`, первая строка `AUTH пароль`, ответ `OK`. Дальше каждая строка - команда; служебные: `PING`, `QUIT`.
Пять неверных паролей подряд - вход закрыт на минуту. Пароль и команды идут открытым текстом: только доверенная сеть или ВМ.
В VirtualBox: сеть NAT + проброс порта 7077, либо сеть «сетевой мост».
Проверка: сценарий `rcon` (ci/kira_vm.py), хост-тест tests/rcon_test.c.
