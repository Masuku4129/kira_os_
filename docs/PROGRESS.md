# Ход работ

План (утверждён 31.10.2026): стенд -> этап 1 (стабильность) -> трёхуровневый Разум -> arch/ и ARM64 ->
capabilities и программы WASM -> сеть -> виртуальные машины для недоверенного кода.
Правило: каждое изменение проходит тесты на хосте (-Werror) и сценарии стенда (`ci/`, GitHub Actions, QEMU+KVM).

## Сделано
- v29: база (ядро, оболочка, Разум, KiraFS v2, FAT, USB, диски) - в репозитории с первого коммита.
- Стенд: `ci/kira_vm.py` + `ci/scenarios.py` - 12 сценариев (диски virtio/IDE/SATA/NVMe, 1-8 ядер, изоляция,
  USB с хабом и флешкой на xHCI и UHCI, нагрузка «20 plasma», «3D + plasma + burnall»), журнал, снимки экрана.
- Часы ПК: настройка UTC / местное (Limbo и Windows держат в часах местное время) - время больше не сбивается на пояс.
- `-Werror` в сборке ядра и тестах на хосте.

## В работе (этап 1)

  выводятся на экран (было: одна охватывающая рамка, один поток).

- Дальше: бюджеты программ и допуск запусков; предел загрузки ядер (коэффициент) под управлением Разума;
  очереди потоков на каждом ядре с переносом между ядрами.
