## Этапы компилятора (дорожка M)
- M1 хост: лексер/препроцессор (#include, #define, #if), разбор C99-подмножества, типы, структуры, указатели, функции; тесты на корпусе программ, результат сверяется с clang.
- M2 хост: кодогенерация x86-64 прямо в машинный код (без внешнего ассемблера), ELF исполняемого формата Киры.
- M3 на Кире (нужен до L): `kcc` собирается как программа Ring 3 (самосборка не требуется), команда `cc файл.c -o программа`; libc-lite (malloc, строки, printf-лайт, файлы песочницы).
- M4: AArch64-бэкенд, затем пересборка BSD-драйвера на устройстве по `drvget build`.
Лицензия: пишем сами (чистый C), чужой код не берём без явной совместимой лицензии (TinyCC — LGPL, не берём).

5. Ничего из чужого GPL-кода в образ.

## Безопасность слоя драйверов (сборка на устройстве)
Подписей GitHub нет, поэтому защита другая: `drvget install <имя>` показывает пользователю источник (URL, лицензия BSD/MIT/ISC из списка разрешённых), SHA-256 исходников и запрашиваемые права (MMIO/DMA/IRQ/PCI-устройство) и ставит только после явного подтверждения в консоли; загрузка идёт по HTTPS с проверкой цепочки (`/etc/ssl/roots.der`); хэш исходников и собранного ELF записываются в `/drv/<имя>.rec`, при загрузке `drvd` сверяет хэш ELF; права драйвера ограничены его устройством. Без IOMMU DMA-устройство может писать в любую память — предупреждение показывается при установке.
