## Этапы компилятора (дорожка M)
- M1 хост: лексер/препроцессор (#include, #define, #if), разбор C99-подмножества, типы, структуры, указатели, функции; тесты на корпусе программ, результат сверяется с clang.
- M2 хост: кодогенерация x86-64 прямо в машинный код (без внешнего ассемблера), ELF исполняемого формата Киры.
- M3 на Кире: `kcc` собирается как программа Ring 3 (самосборка не требуется), команда `cc файл.c -o программа`; libc-lite (malloc, строки, printf-лайт, файлы песочницы).
- M4: AArch64-бэкенд, затем пересборка BSD-драйвера на устройстве по `drvget build`.
Лицензия: пишем сами (чистый C), чужой код не берём без явной совместимой лицензии (TinyCC — LGPL, не берём).

## Правила экономии токенов
1. Один чат = один пакет; не читать журналы стенда целиком, только `ci/brief.sh` с шаблоном.
2. Помощники: ≤2 одновременно; задание — ссылкой на раздел docs/ROUND2.md, а не пересказом.
3. Не опрашивать фоновые задачи; ждать уведомлений.
4. Стенд на ветках пакетов — только нужные сценарии; полный — в конце (T).
5. Ничего из чужого GPL-кода в образ.

H0 → I и J (параллельно, 2 помощника) → K → L → N → B → M1–M4 (параллельно с чем-либо по бюджету) → H → T.
