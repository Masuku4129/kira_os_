# Технология работы (пакеты A–H)

## Правила для всех (люди, помощники)
- Язык: комментарии, сообщения ядра и отчёты — по-русски. Чистый C/asm, без заглушек и имитаций; чего нет — писать честно. Ничего не зашивать: данные — из ACPI/дерева устройств.
- Каждая правка проходит стенд: `git push origin <ветка>`, затем `ci/brief.sh HEAD 'шаблон' сценарии...` (ждёт прогон, печатает сбои). Результат ветки пакета — в `ci-results-<ветка>`, не в `ci-results`. Сначала `tests/run_host_tests.sh` локально.
- Коммиты: `git -c user.name=Claude -c user.email=noreply@anthropic.com commit`, в конце сообщения:
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` и `Claude-Session: https://claude.ai/code/session_01XvKRdjNwfsFHEeh31WA93a`.
- Токен GitHub не использовать и не хранить; только интеграция/`gh`.
- Помощник работает в ветке `pkg-<буква>` от `stable`, только в границах своего пакета (чужие файлы не трогать без нужды; если нужно — коротко отметить в отчёте). В `docs/PROGRESS.md` добавить раздел пакета; `docs/HANDOFF.md` — только строки [ОСТАЛОСЬ]/[СДЕЛАНО] своего пакета.
- Отчёт в конце: что сделано и ПРОВЕРЕНО стендом (список сценариев), что НЕ проверено и почему, что не удалось. Не больше 25 строк.

## Ветки
`main` — выпущенное; `stable` — интеграция; `pkg-A..H` — пакеты. Слияние пакетов в `stable` — только основной сессией, после зелёного стенда.

## Пакеты
| Пакет | Содержание | Исполнитель |
|---|---|---|
| A | capabilities для всех системных вызовов | основная сессия |
| B | ACPI AML (`_PRT`) → прерывания e1000 (Limbo, реальные ПК) | основная сессия |
| C | IP-фрагменты (сборка), IPv6 (ND, SLAAC, ICMPv6, TCP/UDP) | помощник |
| D | TLS: Ed25519, сертификаты RSA-PSS, AES без таблиц, OCSP stapling, повторное использование сессий | помощник |
| E | Звук: фильтр при понижении частоты, Sound Blaster 16 | помощник |
| F | Прогрессивный JPEG; ускорение интерпретатора WASM | помощник |
| G | ARM: пул DMA без кэша для плат без согласованности | основная сессия |
| H | Стабильность: fuzz системных вызовов, долгие прогоны, утечки (после A–G) | помощник, в конце |
