# Решения по технологиям (проверено на коде, 2026-11-15)

Критерий: технология включается, если (а) есть конкретная проблема в текущем коде, (б) она её решает измеримо, (в) цена в сложности и в доверенной кодовой базе меньше выигрыша.
Статусы: **ДА** (в системе), **СДЕЛАНО** (внедрено при этой пересборке), **ПЛАН** (нужно, в очереди с критерием), **НЕТ** (не нужно сейчас, причина).

## Языки
| Технология | Решение | Основание |
|---|---|---|
| C, Assembly | ДА | всё ядро и службы; asm только для входов, контекста, загрузчика |
| KCC | ДА | собственный компилятор C на устройстве (x86-64, AArch64); развитие — отдельный поток |
| WASM | ДА | переносимые приложения (ADR-0001) |
| Rust (no_std) | НЕТ для ядра и драйверов; ДА как источник WASM | второй язык в доверенной базе удваивает toolchain и аудит. Для приложений Rust уже доступен через `wasm32-wasi` (см. ниже) без изменений ядра |
| Python, Bash | ДА только как инструменты сборки и CI | в образ ОС не входят |
| SPARK Ada, Zig | НЕТ | нет проблемы, которую они решают лучше C+проверок; не оценивались на коде |

## Архитектурные технологии
| Технология | Решение | Основание в коде |
|---|---|---|
| Capability-микроядро | ПЛАН (направление) | права есть (`caps.c`), но службы живут в ядре: 96 нарушений уровней в `layer_violations.baseline`, прежде всего 3→6 и 6→8. Каждое устранённое нарушение — шаг к микроядру; декларации без этого — шум |
| HAL | ДА | `arch/x86_64`, `arch/aarch64` за общими интерфейсами |
| IPC | ДА | порты и разделяемая память (`kobj.h`: KOBJ_PORT, KOBJ_SHM), zero-copy через SHM уже работает (графсервер) |
| IOMMU / DMA | ДА, **приоритет** | VT-d частично (`iommu_vtd.c`), AMD-Vi и SMMU лежат в `attic/` без сборки; без IOMMU драйвер с busmaster читает всю память. Критерий: сценарий QEMU `-device intel-iommu` с попыткой DMA вне окна |
| WASM runtime | ДА | `userland/wasm.c`: интерпретатор и JIT x86-64, differential-тесты |
| KIRA IR / SSA | ПЛАН | текущий IR KCC линейный, не SSA (`kcc/ir.c`). Цель «скорость на уровне clang» без SSA недостижима (нет mem2reg, GVN). Начинать, когда будет бенчмарк-эталон; не в этой пересборке |
| MLIR | НЕТ | огромная зависимость, противоречит самосборке на устройстве |
| Copy-on-Write | ПЛАН, **высокий** | у KiraFS нет журнала, живучесть при обрыве питания держится на порядке записей (`kfs.c`, «как в v1»). COW-метаданные дадут атомарность без журнала. Критерий: power-cut тест (обрыв на каждой записи) |
| CAS / Merkle DAG | НЕТ для ФС; ДА для образов и обновлений | целостность обновлений уже SHA-256 манифестом; общий CAS в ФС усложнит без выигрыша |
| LSM-tree | НЕТ | выигрыш на записи терабайтов; у нас диски в мегабайтах |
| B+Tree | ПЛАН | индекс каталогов KiraFS, когда число файлов в каталоге станет проблемой; сейчас не измерено |
| Async I/O | ПЛАН | сейчас блокирующие вызовы; нужна очередь завершений (virtio/NVMe её имеют). После COW |
| Zero-copy | ДА | SHM; расширять по месту |

## Форматы
| Формат | Решение | Основание |
|---|---|---|
| ELF, WASM, FDT, ISO, IMG, KiraFS | ДА | см. `FORMATS_AND_LANGUAGES.md` |
| WASI 0.1 | **СДЕЛАНО** (подмножество) | модули из C/Rust/Zig для `wasm32-wasi` запускаются без собственного ABI: `fd_write`, `proc_exit`, `clock_time_get` (монотонные), `args_*`, `environ_*` (пусты), `fd_close/seek/fdstat_get` (fd 0–2). Файлы, сокеты, `random_get` не поддержаны и отвергаются при загрузке. Тест `tests/run_host_tests.sh`, интерпретатор и JIT |
| «UELF» | НЕТ такого формата | в сборке `UELF` — всего лишь переменная со списком пользовательских ELF-файлов, а не формат |
| FlatBuffers, Cap'n Proto, CBOR | НЕТ сейчас | сообщения IPC — структуры фиксированной ширины; схемный формат нужен, когда появятся независимые реализации и версионирование. Не оценивалось на коде |
| Arrow, Parquet | НЕТ | аналитика больших таблиц; Mind хранит малые кольцевые буферы |
| Zstd | ПЛАН (низкий) | уменьшит архивы обновления; декодер ≈1000 строк, пока не нужен |
| JSON, YAML | JSON — только в инструментах | в ядре не нужен |
| PEM/DER | ДА | `x509.c` разбирает DER; PEM — по необходимости |

## Инструменты
LLVM/Clang, QEMU, Limbo, Git/GitHub, CI — ДА. GRUB — только запасной путь (основной — собственный загрузчик, `kira.iso`).

## Что внедрено при этой пересборке
1. Подмножество WASI 0.1 (выше) — единственное из списка с немедленной пользой: открывает программы на нескольких языках без изменений ядра.
2. Исправлена критическая ошибка декодера WASM: знаковый LEB128 не расширял знак, и все отрицательные константы читались как положительные (код из ветки `main`). Исправлены также ложные отказы на «избыточные» LEB (wasm-ld дополняет их по спецификации). Покрыто существующим тестом «интерпретатор = нативный вывод» и тестом WASI.
