# Kira OS (ОС Кира)

Обновлено: 2026-11-17

Kira OS — операционная система для стационарных ПК и программно-аппаратных промышленных комплексов общего и специального назначения. Микроядро на C и ассемблере без стандартной библиотеки; процессоры x86_64 и ARM64; загрузка BIOS и UEFI.

**Статус:** предварительная версия (PREVIEW). Проверена в эмуляторе QEMU и тестами на хосте; на реальном оборудовании ещё не проверялась.
**Лицензия:** все права защищены (см. [LICENSE](LICENSE)).

## Что внутри
Многоядерность и собственный планировщик, изоляция процессов и драйверов (права доступа, защита памяти W^X, изоляция обмена данными устройств IOMMU), файловые системы KiraFS и FAT, диски ATA/AHCI/NVMe/virtio, сеть, USB, графическая оболочка, собственный компилятор KCC, подсистема «Разум», чёрный ящик для записи сбоев, удалённая консоль. Подробное описание каждой подсистемы с назначением, файлами и проверкой — в [docs/SYSTEMS.md](docs/SYSTEMS.md).

## Быстрый старт
- Сборка: `./build_clang.sh --no-run` (нужны clang, ld.lld, nasm, grub-mkrescue). Запуск: `./build_clang.sh --vnc`.
- Тесты на хосте: `bash tests/run_host_tests.sh`.
- Тесты в QEMU: `python3 ci/kira_vm.py --all` (сценарии в `ci/scenarios.py`); для ARM64 — `python3 ci/arm64_vm.py`.
- Проверка слоёв архитектуры: `python3 ci/check_layers.py`. Проверка документов: `python3 ci/check_docs.py`.
